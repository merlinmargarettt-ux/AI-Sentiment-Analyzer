# AI Sentiment Analyzer

## Overview
This project is a Machine Learning application that classifies text reviews as Positive or Negative using Natural Language Processing (NLP).

## Features
- Sentiment prediction for text reviews
- Text preprocessing and vectorization
- Machine Learning classification using Scikit-learn

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NLP
- Pickle

## Files
- app.py
- train_model.py
- model.pkl
- vectorizer.pkl
- reviews.csv
